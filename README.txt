SANVILA WEBSITE UPDATE — PRIVACY POLICY

Files included:
- index.html: your provided homepage with a Privacy Policy link added to the footer.
- privacy-policy.html: new public Privacy Policy page.
- css/style.css: your supplied stylesheet, included so the folder structure matches the homepage stylesheet reference.

How to publish:
1. Download and unzip this package.
2. In your GitHub repository (sanvila-website), replace the existing root index.html with the included index.html.
3. Add privacy-policy.html to the repository root (same level as index.html).
4. Ensure the stylesheet remains at css/style.css. If your repository already has the same stylesheet, you can keep the existing file; the included one is the copy supplied for this edit.
5. Commit and push the changes. Vercel should redeploy automatically if it is connected to this repository.
6. After deployment, open https://sanvila-website.vercel.app/privacy-policy.html in a private/incognito window and confirm it loads publicly.
7. Only after verifying the page is live, copy that exact URL into Google Ads' Privacy policy URL field.

Note: This package does not deploy anything or modify your GitHub repository automatically. Please review the policy wording and business contact details before publishing. The policy is a general template, not legal advice.
